# 🥛 เปรม นมสด (Prem Nomsod) - Landing Page

เว็บไซต์ **Landing Page** สำหรับร้าน **"เปรม นมสด"** ร้านนมสดแท้ ขนมปังปิ้งเตาถ่าน ปังเย็นภูเขาไฟ และของทานเล่นยามค่ำคืน ย่านถนนจิระ อำเภอเมือง จังหวัดบุรีรัมย์

![Logo](logo.png)

---

## 🌟 จุดเด่นของเว็บไซต์ (Features)

* **🎨 Warm Night Cafe Design:** ดีไซน์โทนสีน้ำเงิน-ฟ้า-เหลืองทอง สะท้อนบรรยากาศร้านนั่งชิลล์ยามค่ำคืนใต้แสงไฟปิงปอง
* **⏱️ ระบบตรวจจับสถานะร้านแบบ Real-time:** ตรวจสอบเวลาตามอุปกรณ์ผู้ใช้ หากอยู่ในช่วงเวลาทำการ **17:00 – 22:00 น.** จะแสดงสถานะเปิดบริการ (`🟢 ขณะนี้ร้านเปิดบริการ`) หากอยู่นอกเวลาจะแสดงสถานะปิดบริการอัตโนมัติ
* **🍽️ เมนูแบบ Interactive Tabs:** กรองดูเมนูตามหมวดหมู่ได้สะดวกรวดเร็ว (เครื่องดื่ม, ปังปิ้ง & ของหวาน, ของทานเล่น)
* **🖼️ Atmosphere Gallery & Lightbox Modal:** ดูภาพบรรยากาศร้านขนาดใหญ่เต็มจอพร้อมคำบรรยาย
* **🔗 Direct Facebook Page Link:** เชื่อมต่อกับเพจ Facebook ทางการของร้าน [เปรม นมสด](https://web.facebook.com/premnomsod)
* **📱 100% Fully Responsive:** รองรับการใช้งานอย่างสมบูรณ์แบบบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
